진행 중인 실종 사건 지도

경찰과 가족이 신고한 실종 사건의 실종 지점이 실제 지도(OpenStreetMap) 위에 점으로 표시됩니다. 점 또는 아래 목록에서 실종자를 선택하면 상세 지도가 열립니다. 모든 데이터는 구글시트에서 자동으로 불러오며, 20초마다 자동 새로고침됩니다. (지도 표시에는 인터넷 연결이 필요합니다)

지도를 클릭해 실종 위치를 선택하세요 (ESC: 취소)

경찰청 공개 실종자 정보

경찰청 실종자 공개 API에서 실제 실종자 정보를 불러와 구글시트 DB에 자동으로 등록합니다(중복 등록 방지). 등록된 사람은 위쪽 "진행 중인 실종 사건 지도" 목록에 자동으로 함께 나타나며, 이후 API 응답에서 사라진 사람(발견·해제 추정)은 삭제되지 않고 자동으로 "사건 종료" 상태로 전환됩니다. 완전 삭제는 경찰 인증 계정만 가능합니다.
